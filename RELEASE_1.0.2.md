## 📦 Version 1.0.2 – Settings Updates & Loading Fixes

### 🚀 Changes

* **Toxic Nicknames Setting:**
  Added a new toggle in the Settings menu to enable or disable toxic nicknames. The setting is disabled by default.

* **Banner Ad Placeholder:**
  Prepared the UI layout in the game screen by allocating space for upcoming banner advertisements.

* **Localization Updates:**
  Added new translations for the About section and the new settings options in both English and Turkish.

### 🐛 Bug Fixes

* **Startup Loading Fix:**
  Resolved an issue where game data and preferences were loading asynchronously after the application started, causing a delayed render. Essential data is now fully loaded before the application renders.

## 📦 Sürüm 1.0.2 – Ayar Güncellemeleri ve Yükleme Düzeltmeleri

### 🚀 Değişiklikler

* **Küfürlü Lakaplar Ayarı:**
  Ayarlar menüsüne toksik/küfürlü lakapları açıp kapatabileceğiniz yeni bir seçenek eklendi. Bu özellik artık varsayılan olarak kapalı gelmektedir.

* **Reklam Alanı Hazırlığı:**
  Oyun ekranının alt kısmında, ileride eklenecek olan banner reklamlar için bir alan ayrıldı ve arayüz buna göre düzenlendi.

* **Yerelleştirme Güncellemeleri:**
  Hakkında (About) sayfası ve yeni eklenen ayarlar için İngilizce ve Türkçe dil dosyalarına çeviriler eklendi.

### 🐛 Hata Düzeltmeleri

* **Uygulama Açılışı Yükleme Düzeltmesi:**
  Uygulama açılırken oyun verilerinin ve kullanıcı ayarlarının geç yüklenmesine (asenkron yükleme sorunu) bağlı olarak arayüzde oluşan gecikme düzeltildi. Artık tüm gerekli veriler uygulama ekrana gelmeden önce okunuyor.
