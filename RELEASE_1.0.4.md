## 📦 Version 1.0.4 – Bulk Round End & Score Enhancements

### 🚀 Changes

* **Okey Atarak Elden Bitti (-404):**
  Added a new finish type "Okey Atarak Elden Bitti" which deducts 404 points from the winner.

* **Distinct Colors for Finish Types:**
  Updated the score input dialog to use distinct colors for different finish types (Normal = Green, Elden = Blue, Okey = Purple, Okey+Elden = Orange) for better visual differentiation.

* **Bulk Round End Dialog (101 Mode):**
  Tapping the table in the center of the Game Screen now opens a bulk round end dialog. This allows you to select the winner, the finish type, and input the remaining tile scores for other players all at once, similar to the Americano mode.

* **Double (Çiftli) Indicator in Dialogs:**
  A golden "2x" badge is now displayed next to the player's name in the bulk round end dialog if they are playing double (Çiftli).

### 🐛 Bug Fixes

* None

## 📦 Sürüm 1.0.4 – Toplu Tur Sonu ve Puan Geliştirmeleri

### 🚀 Değişiklikler

* **Okey Atarak Elden Bitti (-404):**
  Bitiren oyuncudan 404 puan düşen yeni "Okey Atarak Elden Bitti" bitirme türü eklendi.

* **Bitirme Türleri İçin Farklı Renkler:**
  Puan giriş dialogundaki bitirme türleri daha kolay ayırt edilebilmesi için renklendirildi (Normal = Yeşil, Elden = Mavi, Okey = Mor, Okey+Elden = Turuncu).

* **Toplu Tur Sonu Dialogu (101 Modu):**
  Oyun ekranının ortasındaki masaya tıklandığında artık toplu tur sonu dialogu açılıyor. Tıpkı Americano modunda olduğu gibi kazananı, bitirme türünü ve diğer oyuncuların kalan taş puanlarını tek seferde girebilirsiniz.

* **Dialoglarda Çiftli Göstergesi:**
  Toplu tur sonu dialogunda, çiftli giden oyuncuların isimlerinin yanında altın rengi "2x" rozeti gösteriliyor.
